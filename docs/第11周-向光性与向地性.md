# 第11周：向光性与向地性

## 本周目标

在第10周动态分枝生成的基础上，引入**向光性 (Phototropism)** 与 **向地性 (Gravitropism/Geotropism)** 机制，实现植物枝干朝向光源生长、根系向下生长的物理/环境约束，并加入多光源合成、光照阴影遮挡判断、受光率对生长速度的实时反馈以及 UI 与 WebSocket 交互控制。

## 核心模块

- `EnvironmentParams`：支持多光源（方向光 `Directional` 与点光源 `Point`）定义、光源位置/方向/强度/颜色控制、向光性权重 `phototropismWeight`、向地性权重 `gravitropismWeight`、有效光向合成 `calculateEffectiveLightDirection` 以及简化光照遮挡率计算 `calculateLightExposure`。
- `DynamicBranchingSystem`：在生成新节点及计算分枝生长方向时，将惯性方向、合成光矢量与向地矢量（茎枝向上 $+Y$ / 根系向下 $-Y$）加权混合；同时根据节点局部受光率调节生长速度与健康度衰减。
- `SimulationEngine`：桥接环境参数多光源与向性设置，将局部节点坐标集传递给 `GrowthResourceState`，提供向性调节槽函数。
- `Renderer` & `Light`：视口渲染支持多光源，并在 OpenGL 3D 视口中以 3D Gizmo 方式呈现光源的位置与状态。
- `EngineWindow` & `WebSocketServer`：提供向光性/向地性权重滑块、光源参数控制 UI 面板以及 WebSocket `set_tropism` 与 `set_light_position` 指令响应。

## 核心向性与环境算法

1. **多光源有效光向合成 (Effective Light Direction)**:
   对于节点位置 $P$，合成光矢量由所有启用光源的加权和计算得到：
   $$\vec{L}_{effective} = \text{normalize}\left( \sum_i I_i \cdot \text{attenuation}(d_i) \cdot \vec{l}_i \right)$$
   点光源根据距离 $d_i$ 按照二次多项式 $1 / (1 + a \cdot d + b \cdot d^2)$ 进行强度衰减。

2. **简化光照阴影遮挡 (Light Occlusion)**:
   沿着点 $P$ 到各光源的射线方向，检测是否有其他骨架节点落在遮挡圆锥/半径 `occlusionRadius` 范围内。若被遮挡，受光率按遮挡衰减因子 `shadowFactor` 比例降低。

3. **向光性与向地性方向混合 (Tropism Blending)**:
   - **茎/枝干 (Stem/Branch)**：向光矢量为 $\vec{L}_{effective}$，负向地性矢量为 $+Y$ (向上)。
   - **根系 (Root)**：正向地性矢量为 $-Y$ (向下)。
   - **混合公式**：
     $$\vec{D}_{target} = \text{normalize}\left( (1 - w_p - w_g) \cdot \vec{D}_{inertia} + w_p \cdot \vec{D}_{photo} + w_g \cdot \vec{D}_{grav} \right)$$

4. **生长速度与健康度反馈**:
   - 生长速度调整：$\text{growthSpeed} = 0.3 + 0.7 \cdot \text{lightExposure}$。
   - 处于深度阴影区域（受光率低于阀值）的枝干和叶片，健康度衰减速率 `healthDecayRate` 增加，模拟自然自剪/落叶现象。

## 交互与 WebSocket 协议

- **WebSocket 设置向性权重**:
  ```json
  { "type": "set_tropism", "phototropism": 0.65, "gravitropism": 0.40 }
  ```
- **WebSocket 设置光源位置**:
  ```json
  { "type": "set_light_position", "id": 1, "position": [3.0, 6.0, 2.0] }
  ```
