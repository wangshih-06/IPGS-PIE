# 第10周：动态分枝生成

## 本周目标

在第9周生长时间轴的基础上，将植物生长从“连续缩放”扩展为“结构事件 + 几何动画”：分枝和叶片按照年龄、资源和层级规则逐步出现，并记录可恢复的生长关键帧。

## 核心模块

- `DynamicBranchingSystem`：处理年龄触发、资源概率、层级/数量上限、顶端优势、停止生长和死亡。
- `GrowthEventManager`：记录分枝创建、枝干死亡、生长停止、叶片萌发、叶片衰败和关键帧捕获事件，并支持 JSON 持久化。
- `GrowthKeyframeStore`：保存完整 `PlantModel` JSON 快照，支持按索引恢复。
- `SimulationEngine`：在每个生长 tick 中先推进年龄，再更新动态结构，最后应用连续生长样本并重建表面。

## 动态规则

1. **年龄触发**：节点年龄达到 `branchStartAge` 后，按 `branchInterval` 分桶，避免同一节点在同一年龄重复尝试。
2. **资源概率**：分枝概率由 `branchProbability × resource^resourceExponent` 计算；光照、含水量、营养、温度和风共同形成资源可用度。
3. **层级控制**：通过 `maxDepth`、`maxChildrenPerNode` 和 `maxTotalBranches` 限制结构规模。
4. **顶端优势**：顶端节点使用完整概率；受侧枝竞争影响的节点按 `1 - apicalDominance` 衰减。
5. **平滑生成**：新枝干从 `growthProgress=0.04` 开始，叶片从 `0.03` 开始，并按 `smoothingYears` 逐步增长，避免瞬间跳变。
6. **停止和死亡**：年龄达到 `growthStopAge` 或资源低于 `resourceThreshold` 时停止生长；持续资源不足会降低健康度，低于 `deathThreshold` 后递归标记枝干子树死亡。
7. **叶片萌发**：节点满足 `leafSproutAge` 后按资源概率生成叶片，叶片同样具有独立成长进度和健康度。

## 关键帧与事件

`SimulationEngine` 在初始状态保存快照，并默认每经过1个植物年龄单位自动捕获关键帧。也可以调用：

```cpp
engine.captureGrowthKeyframe(QStringLiteral("flowering"));
engine.saveGrowthKeyframes(QStringLiteral("growth_keyframes.json"), &error);
```

恢复关键帧：

```cpp
PlantModel restored;
keyframes.restore(0, &restored, &error);
```
