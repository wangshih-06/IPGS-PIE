# 第13周：植物物理模型

## 本周目标

本周在已有 `PlantModel` 植物骨架、生长时间轴和环境参数之上，新增基于 **Position-Based Dynamics (PBD)** 的结构物理层。它将每个植物节点视为质量点，将父子枝干、三节点链与同父分叉分别转换为长度、弯曲和分枝夹角约束。

本周交付：

1. `PlantMassPoint` 质量点模型与枝干约束边。
2. 固定根节点、质量和枝干刚度定义。
3. PBD 长度、弯曲和分枝夹角约束。
4. 包含重力、风力、阻尼、子步进和多次迭代的求解器。
5. Qt/OpenGL 物理调试模式和 `PlantPhysicsDemo` 回归程序。

`PlantPhysicsSolver` is built as a standalone static library. `SimulationEngine` owns a solver instance, supplies the current plant skeleton, and copies the resolved positions back to `PlantModel`. The separation keeps structural dynamics independent from OpenGL rendering.

## 1. 质量点与固定根

Every `PlantNode` becomes one `PlantMassPoint`. A point stores the node id, parent id, current and predicted positions, velocity, mass, inverse mass, and a fixed flag. The root node sets `inverseMass = 0`, so it cannot move during integration or constraint projection; the above-ground skeleton therefore remains attached to the soil.

Mass is estimated from a cylindrical segment and clamped to a positive lower bound:

```text
m = max(minimumMass, massDensity * pi * radius^2 * segmentLength)
w = 0                 (fixed root)
w = 1 / m             (movable point)
```

Minimum radius and segment-length guards prevent degenerate geometry from producing zero mass. A branch can expose `Branch::stiffness`; when unavailable the solver uses `defaultLengthStiffness`.

## 2. PBD 长度约束

Every parent-child skeleton edge creates one `PlantLengthConstraint`, whose rest length is captured from the plant geometry. For endpoints `i` and `j`:

```text
C_length(x) = |xj - xi| - restLength = 0
```

The solver projects the positional error along the normalized edge direction and weights each correction by inverse mass. A fixed parent receives no correction, while a movable child receives the appropriate remaining correction. The branch stiffness is normalized to `[0, 1]` and applied in each solver pass.

## 3. 弯曲约束

For every grandparent-parent-child chain, the solver creates a `PlantBendingConstraint`. Rather than directly projecting an angle, it preserves the rest **chord length** between the grandparent and the child while the two adjacent length constraints stay active:

```text
C_bend(x) = |x_tip - x_base| - restChordLength = 0
```

With both segment lengths constrained, the chord preserves the original bend. This is intentionally more stable around nearly straight or nearly folded configurations, where a direct angle formulation can have fragile gradients.

## 4. 分枝夹角约束

For every pair of children sharing a parent, `PlantBranchAngleConstraint` records the included rest angle. With branch vectors `a` and `b`, and rest angle `theta0`:

```text
C_angle(x) = dot(normalize(a), normalize(b)) - cos(theta0) = 0
```

The PBD projector uses analytical gradients for the two child positions and the shared parent, applies inverse-mass weighting, then scales the result with the configured branch-angle stiffness. A parent with `n` direct children produces `n * (n - 1) / 2` pairwise angle constraints.

## 5. 迭代求解器与生长同步

One simulation step performs these operations:

1. Split a long frame delta into substeps no larger than `maximumTimeStep`.
2. Integrate external acceleration into movable-point velocity and predicted positions.
3. Project length, bending, and branch-angle constraints for `solverIterations` passes.
4. Perform a final length projection because angular and bending projection can perturb branch lengths.
5. Reconstruct velocity from the position delta, apply damping, and commit the predicted positions.
6. Use `applyToPlant()` to write positions, directions, and segment lengths back to `PlantModel`.

The runtime defaults are 12 iterations, damping `0.985`, gravity `(0, -3.2, 0)`, and a maximum time step of `1/60` second. The standalone regression uses a higher iteration count only to test tight convergence; it is not the production default.

Growing plants can add nodes or change rest geometry. `synchronizeRestConfiguration()` updates mass and rest values without discarding velocities whenever topology is unchanged. If topology differs, it safely rebuilds the mass-point graph. This lets the engine apply growth first and physics second during a growth tick.

## 6. 引擎接入与调试模式

Physics is disabled by default so the recorded-growth replay from Week 12 remains deterministic. When **Enable PBD physics** is selected in the Qt **VIEWPORT** panel, `SimulationEngine` synchronizes the plant, applies gravity and time-varying horizontal wind from `EnvironmentParams::windIntensity`, solves one 1/60-second PBD step, writes the result to the plant model, and rebuilds the implicit surface.

**Physics debug overlay** sends a `PlantPhysicsDebugSnapshot` to the renderer and displays constraint counts and residuals. The color convention is:

| 标记 | 含义 |
| --- | --- |
| 青色线 | 长度约束 |
| 橙色折线 | 弯曲弦长约束 |
| 紫色线 | 分枝夹角约束 |
| 红色十字 | 固定根节点 |
| 绿色十字 | 可运动质量点 |

The panel reports particles (`P`), length constraints (`L`), bending constraints (`B`), branch-angle constraints (`A`), and maximum / mean residuals.

## 当前限制

- No self-collision, terrain collision, or inter-plant collision is solved yet.
- Leaves remain growth/render data and are not independent particles.
- The root position is fixed, but no separate root-orientation or soil-compliance constraint is modeled.
- Pairwise branch-angle construction is quadratic in the number of immediate children; unusually high-order junctions should be capped or sparsified in a later optimization pass.
- This is a structural PBD model, not a full material model with plasticity, fracture, or anisotropic wood mechanics.
