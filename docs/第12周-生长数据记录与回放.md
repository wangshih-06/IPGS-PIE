# 第12周：生长数据记录与回放

## 本周目标

在第 9 周生长时间轴、第 10 周动态分枝和第 11 周环境向性机制的基础上，为系统建立完整的**生长数据记录、时间轴回放、指标统计与导出**能力。

本周完成的交付包括：

1. 每个有效生长时间步保存植物完整状态。
2. 前端时间轴可拖动定位，支持播放、暂停、重置和速度控制。
3. 支持种子、萌发、营养生长、成熟、老化等关键阶段跳转。
4. 统计植物高度、枝干总长度、分枝数、叶片数和冠幅。
5. 在前端绘制可切换的生长变化曲线。
6. 导出 JSON 与 CSV 生长指标；引擎同时提供完整快照 JSON 的文件保存接口。

## 核心实现

### 1. `GrowthDataRecorder`：逐时间步记录器

新增文件：

```text
include/Engine/GrowthDataRecorder.h
src/Engine/GrowthDataRecorder.cpp
```

核心数据结构：

```cpp
struct PlantGrowthMetrics {
    float height = 0.0f;
    float totalBranchLength = 0.0f;
    int branchCount = 0;
    int leafCount = 0;
    float canopyWidth = 0.0f;
};

struct GrowthDataFrame {
    int step = 0;
    float age = 0.0f;
    PlantLifeStage lifeStage = PlantLifeStage::Seedling;
    PlantGrowthMetrics metrics;
    QJsonObject plantState;
};
```

`GrowthDataRecorder` 的职责：

- `capture(const PlantModel&)`：记录年龄、生命周期、五项指标和 `PlantModel::toJson()` 完整快照。
- `nearest(float age)`：寻找与目标年龄最接近的历史帧，用于时间轴回放。
- `truncateAfter(float age)`：当用户回放到过去后继续模拟时，删除该时刻之后的旧未来帧。
- `measure(const PlantModel&)`：计算当前植物结构指标。
- `toJson()`：导出包含完整 `plantState` 快照的回放存档。
- `metricsToJson()`：导出轻量化指标序列，供浏览器曲线渲染和下载。
- `saveJson()` / `saveCsv()`：保存完整 JSON 或指标 CSV 文件。

### 2. 指标统计口径

| 指标 | 实现方式 |
| --- | --- |
| 植物高度 `height` | 活动枝干节点与活动叶片的 Y 轴包围盒高度。 |
| 枝干总长度 `totalBranchLength` | 递归遍历活动父子节点，优先累计节点间欧氏距离；几何距离退化时使用子节点 `length`。 |
| 分枝数 `branchCount` | 活动父子节点连接数量。 |
| 叶片数 `leafCount` | `PlantModel::leaves()` 中活动叶片数量。 |
| 冠幅 `canopyWidth` | 枝干节点和叶片投影在 X-Z 平面的最大跨度。 |

叶片会按自身尺寸的一半扩展其包围范围，因此高度和冠幅能够反映叶片展开后的实际轮廓，而不是仅反映骨架节点。

### 3. `SimulationEngine` 集成与回放策略

`SimulationEngine` 在以下位置写入记录：

- 构造完成后保存年龄为 `0` 的初始帧。
- `onGrowthTickProduced()` 处理完生长、动态结构更新和曲面刷新后保存当前帧。
- `resetGrowth()` 清空旧记录、恢复初始模型后重新保存初始帧。

新增公开槽函数：

```cpp
void seekGrowth(float age);
void jumpToGrowthStage(const QString& stage);
void requestGrowthData();
bool saveGrowthData(const QString& filePath, QString* error = nullptr) const;
bool saveGrowthMetricsCsv(const QString& filePath, QString* error = nullptr) const;
```

#### 时间轴定位

`seekGrowth(age)` 的执行步骤：

1. 从记录器中选取与 `age` 最接近的完整帧。
2. 暂停 `GrowthClock`。
3. 调用 `PlantModel::fromJson()` 恢复该帧的完整植物状态。
4. 重置动态分枝系统和时钟年龄，更新环境时间。
5. 重建 Metaball 场与回放预览曲面。
6. 广播 `growth_state`，刷新浏览器时间轴和指标卡片。

恢复 JSON 快照后，`restoringRecordedFrame_` 会阻止时钟重置信号再次调用 `applyGrowthSample()`。这样可以避免回放时把已经保存的几何尺寸再次缩放，从而消除重复拖动时间轴带来的几何漂移。

#### 从历史帧继续播放

若定位到历史帧后执行播放，新的模拟结果不应与原先的未来数据混合。因此系统会在下一个有效生长 tick 中调用：

```cpp
growthData_.truncateAfter(previousAge + 1.0e-4f);
```

从回放点开始形成新的数据分支。

#### 曲面回放响应优化

完整隐式场的采样与 Marching Cubes 提取计算量较大。为了保证时间轴拖动可用：

- 常规曲面重建采用 `0.18f` 请求采样间距。
- 回放定位使用 `0.24f` 的较粗预览间距。
- `SimulationEngine` 单次表面采样最多保留 `100000` 个标量场样本。

该策略只影响实时预览网格密度，不影响记录中的 `PlantModel` 完整结构状态和五项统计指标。

### 4. 关键阶段跳转

`jumpToGrowthStage()` 依据 `GrowthTimeline` 阈值映射阶段名称：

| 前端标识 | 定位年龄 |
| --- | --- |
| `seed` / `seedling` | `0` |
| `sprout` / `vegetative` | `seedlingEndYear`，默认 `0.5` 年 |
| `growing` | `vegetativeEndYear`，默认 `3.0` 年 |
| `mature` | 成熟区间内约 `1/3` 位置，默认 `12.0` 年 |
| `aging` / `completed` | `matureEndYear`，默认 `30.0` 年 |

阶段跳转最终复用 `seekGrowth()`，因此同样具备完整状态恢复与暂停行为。

## WebSocket 协议

### 浏览器 → C++ 引擎

```jsonc
{ "type": "growth_start" }
{ "type": "growth_pause" }
{ "type": "growth_resume" }
{ "type": "growth_reset" }
{ "type": "growth_seek", "age": 2.5 }
{ "type": "growth_stage", "stage": "mature" }
{ "type": "growth_speed", "speed": 2.0 }
{ "type": "request_growth_data" }
```

速度会被限制为 `0.1x` 到 `8.0x`。

### C++ 引擎 → 浏览器

#### `growth_state`

在开始、暂停、速度变更、每个生长 tick、回放定位和重置后广播：

```jsonc
{
  "type": "growth_state",
  "age": 0.65,
  "lifeStage": "vegetative",
  "mode": 1,
  "speed": 1.0,
  "nodeCount": 513,
  "branchCount": 512,
  "leafCount": 0,
  "height": 4.04,
  "totalBranchLength": 46.03,
  "canopyWidth": 1.69,
  "recordedFrameCount": 42,
  "recordedEndAge": 0.65
}
```

`mode` 使用 `GrowthPlaybackMode` 的整型值；前端以 `mode === 1` 作为实时播放状态。`growth_state` 同时携带当前 `plantState` 完整骨架快照，确保实时预览与指标卡同步。

#### `growth_data`

当浏览器发送 `request_growth_data` 时，返回完整记录帧：`metrics` 用于曲线与指标，`plantState` 用于将画布预览还原到对应时间步。CSV/JSON 指标下载仍由前端输出轻量字段。

```jsonc
{
  "type": "growth_data",
  "schema": "plantsim.growth_recording",
  "version": 1,
  "frameCount": 42,
  "keyStages": [
    { "key": "seedling", "label": "Seedling", "age": 0.0 },
    { "key": "vegetative", "label": "Vegetative", "age": 0.5 },
    { "key": "mature", "label": "Mature", "age": 3.0 },
    { "key": "completed", "label": "Completed", "age": 30.0 }
  ],
  "frames": [
    {
      "step": 0,
      "age": 0.0,
      "lifeStage": "seedling",
      "metrics": {
        "height": 4.04,
        "totalBranchLength": 46.03,
        "branchCount": 512,
        "leafCount": 0,
        "canopyWidth": 1.69
      },
      "plantState": {
        "schema": "plantsim.skeleton",
        "skeleton": { "nodes": [], "leaves": [] }
      }
    }
  ]
}
```

## 前端时间轴与指标曲线

本周前端主要改动集中在：

```text
frontend/src/App.vue
frontend/src/style.css
```

界面包含以下组件：

- **当前指标卡片**：年龄、高度、总枝长、分枝/叶片数、冠幅。
- **记录摘要**：记录帧数、已记录年龄、速度、活跃节点数。
- **时间轴**：HTML `range` 控件；拖动时仅本地预览，松开后才向引擎发送一次 `growth_seek`，避免高频恢复快照。
- **播放控制**：播放/暂停、重置、`0.1x–8.0x` 速度滑块；在线操作等待 `growth_state` 回包确认，超时会提示并保留最后确认状态。
- **离线回放**：引擎不可用时，以 `requestAnimationFrame` 推进 0–30 年示例帧，支持暂停、速度和到末帧自动停止。
- **动态关键阶段**：`growth_data.keyStages` 由 C++ 生长时间轴阈值生成；前端以返回年龄直接 `growth_seek`，不再固定 0 / 0.5 / 3 / 12 / 30 年。离线时则从记录帧的生命阶段变化自动提取。
- **SVG 曲线交互**：可切换高度、总枝长、分枝数、叶片数、冠幅；包含 Y 轴刻度与单位、当前数据点、关键阶段虚线、鼠标悬停 Tooltip（年龄/阶段/指标），点击曲线可直接定位回放。
- **数据导出**：浏览器下载当前指标序列为 UTF-8 BOM CSV 或格式化 JSON。
- **离线回退**：当 WebSocket 未连接时，使用 0–30 年示例数据维持时间轴、曲线和导出功能可用。
- **连接恢复与错误反馈**：WebSocket 意外关闭后按 `1 / 2 / 4 / 8 / 10` 秒指数退避重连，最多尝试 5 次；重连耗尽后切换到离线回放。每个连接回调都按 WebSocket 实例身份校验，避免旧连接事件覆盖新连接状态；后端 `{ "type": "error", "message": "..." }` 会进入回放事件列表并解除待确认操作。

浏览器下载的是轻量指标数据；C++ 的 `saveGrowthData()` 则可保存包含全部植物 JSON 快照的完整回放存档。
